# 지침 생성 E 검증

- 범위: 모든 루프가 공유하는 관측 전 1일차 시작 상태
- 번들 난이도: 47개
- 기본 패배 위험 경로: 224개
- 기여 원자 배치: 난이도당 12~37개
- 합법 3장 조합: 난이도당 40~2,652개
- 전체 47개 계산 시간: 약 0.9초
- C 가짜 조건: 270건 중 1일차 진척 가능 198건, 제외 사유 기록 72건

## 224개 경로 축 재감사

한 경로가 둘 이상의 축을 요구할 수 있으므로 아래 수의 합은 224보다 크다.

| 축 | 관련 경로 |
|---|---:|
| 장소 음모 | 63 |
| 캐릭터 음모 | 78 |
| 불안 | 92 |
| 캐릭터 위치 관계 | 118 |
| 카드로 직접 진척하지 않는 기타 조건 | 16 |

추천의 각 원자 배치는 실제 `resolveActions()`에 넣어 표시한 장소·캐릭터 카운터 또는
위치 관계가 변하는지 전수 대조했다. 장소 음모와 캐릭터 음모는 `Target.kind`를 끝까지
보존하며, 언노운 미끼의 도심 음모도 가짜 역할 후보 캐릭터가 아니라 도심 **장소**에
놓는다.

최악 대응 계약도 실제 해결기로 대조했다. 이동은 같은 대상의 이동 금지, 불안은
불안 -1로 각각 상쇄할 수 있다. 음모 금지는 그날 정확히 1장일 때 그 대상에서만
활성화되므로 서로 다른 두 음모 배치 중 최대 한 곳을 막을 수 있고, 2장 이상 내면
금지끼리 상쇄된다. 47개 난이도의 정적 1순위 추천에서 계산값과 실제 해결값 불일치는
0건이었다.

## C·D 반영

- C의 270건을 그대로 후보로 넣지 않았다. 1일차 카드로 카운터·사건 준비를 한 칸
  이상 진척하는 198건만 원자 배치를 만든다.
- 핵심 인물·친구 후보 사망, 시간 여행자의 낮은 우호처럼 1일차 각본가 카드가 직접
  진척하지 못하는 72건은 제외 이유를 화면에 남긴다.
- D는 후보를 만들지 않는다. 보장 진척과 무대응 진척이 같은 조합끼리만, 역할 능력
  대신 카드로 처리해 노출을 아끼는 정도를 정렬 근거로 쓴다.
- 모든 추천에는 카드가 막힐 수 있다는 교환을 함께 표시한다.

## 공식 기본편 8편 `mastermindHints` 대조

E는 공식 지침을 복제하는 운영서가 아니라 A의 정적 1순위·대안과 C의 즉시 미끼만
전수하는 계산기다. 따라서 공식의 블러프·우호 금지·후속 날짜 운영은 후보 생성에서
의도적으로 빠진다.

| 각본 | 공식 첫날 내용과의 관계 |
|---|---|
| basicTragedy:1 | 공식은 연쇄 살인마가 불명일 때 음모 1장과 불안 2장으로 분산한다. E도 카운터 분산은 만들지만 A 경로 진척을 우선해 대상·카드 강도는 다르다. |
| basicTragedy:8 | 공식의 도심 음모 배치와 겹친다. 학교 음모·재벌가 손녀 불안 대신 A의 조건부 핵심 인물 경로와 C 미끼가 남는 차이를 표시한다. |
| basicTragedy:9 | 공식은 2일차 자살과 마녀 우호 견제를 중심으로 설명한다. E는 1일차 직접 진척만 내므로 병원·학교 음모와 사건 불안을 제시한다. |
| basicTragedy:10 | 공식은 루프 상황에 따른 여러 역할 경로를 설명하고 고정 3장을 주지 않는다. E는 A 대안과 즉시 미끼로 정적 3장을 채운다. |
| basicTragedy:11 | 공식의 학교 음모+2·신사 음모+1·병원 블러프와 달리, E는 블러프를 제외하고 A의 사망 경로와 C의 캐릭터 미끼를 진척한다. |
| basicTragedy:12 | 공식의 재벌가 손녀 불안과 겹친다. 하수인 불안·여학생 우호 금지는 각각 시작 장소 선택과 비진척 제어 카드라 E 후보에서 빠진다. |
| basicTragedy:13 | 공식은 고정 첫날 3장보다 사건·역할의 얽힘을 직접 판단하게 한다. E는 청부업자 경로를 정적으로 전개한다. |
| basicTragedy:14 | 공식의 신사·병원·소녀 음모 분산 중 신사 장소와 소녀 캐릭터 축을 회수한다. 능력 사용은 D의 노출 교환으로만 평가한다. |

공식과 다른 행을 숨은 가중치로 맞추지 않는다. 화면에는 각 배치의 근거와 최악 대응,
능력 대신 카드를 쓸 때의 은폐 교환을 남겨 사용자가 루프 상황에 맞게 바꿀 수 있게 한다.

## 계산 범위 결정

1일차 전수는 47개 난이도 합계 약 0.9초라 게임 전 계산에 충분하다. 1~2일차는 각
3장 조합에 합법 주인공 3장 대응과 다음 상태의 새 조합이 곱해진다. 현재 목적은
오프닝 북 전체 열거가 아니며, 1일차에서 이미 `어떤 대응이 와도` 남는 진척을 실제
해결기로 검증할 수 있으므로 E의 고정 범위는 1일차다.
