# Section 2-C 행동 동치류 계측 — `firstSteps:2`

- 실행일: 2026-08-20
- 계측 코드: `tools/phase5-feasibility/measure-action-equivalence.ts`
- 범위: 1일차 초기 결정 상태 1개와 실제 엔진으로 만든 2일차 결정 상태 9개
- 결론: 행동 동치류는 수백 개가 아니라 **수천~만 단위**다.

## 동치의 두 의미

해결 전의 즉시 후속 canonical 상태는 `placed`를 보존한다. 따라서 P2 직후에는 서로
다른 각본가 행동 63,360개가 그대로 63,360개 상태이고, 고정 P2의 P3 직후에도 서로
다른 대응 368,640개가 그대로 구분된다. 이 의미에서는 병합이 없다.

전략 탐색에 쓸 수 있도록 다음 **P4-폐쇄 동치**를 별도로 측정했다.

- 각본가 행동: 모든 합법 주인공 대응에 대해 같은 P4 후속 투영을 만드는 두 행동을
  같은 함수 동치류로 묶는다.
- 주인공 대응: 출발 상태와 각본가 행동 하나를 고정하고, 같은 P4 후속 투영을 만드는
  대응을 묶는다.

P4 후속 키에는 캐릭터별 생사·위치·우호·불안·음모, 장소별 음모, 각본가 1회 카드
소진 2비트, 주인공별 1회 카드 소진 9비트를 넣는다. 경로, 해결 전 배치 카드, 공개
trace와 P5 이후 결과는 뺀다. 이는 1일차 34,516,856개를 확정한 소유자별 정확 P4
투영과 같은 경계다.

각본가 함수 서명은 각 대상에서 가능한 주인공 카드별 국소 결과와 음모 금지의 전역
활성/비활성 결과를 모두 포함한다. 따라서 단일 관측 P3에서 우연히 같은 결과가 난
행동을 합치지 않고, 모든 합법 P3 대응에서 같은 후속 상태인 경우만 합친다.

## 1일차 초기 상태

| 행동층 | 원시 행동 | P4-폐쇄 동치류 | 병합 배수 |
|---|---:|---:|---:|
| 각본가 P2 | 63,360 | **15,558** | 4.07배 |
| 주인공 P3, 고정 P2 10개 | 368,640 | **9,308~12,504**, 중앙값 10,567 | 29.48~39.60배 |

각본가 동치류의 최대 크기는 540개다. P3 수치는 canonical P2 placement SHA-256이
작은 순서의 10개를 고정한 분포이며, 하나의 P2로 외삽하지 않았다.

## 실제 엔진 대조와 재현성

각 대표 상태에서 처음 100개 결합 행동, 총 1,000개를 `validatePlacement()`와 실제
P2→P3→P4 엔진으로 해결했다. 예측 키와 실제 해결 뒤 생사·위치·카운터·장소 음모·
소유자별 소진 자원이 모두 일치했다.

별도 프로세스와 별도 출력 디렉터리에서 두 번 실행했다. 대표 상태와 P2 표본별
세부 측정의 diff는 없었고 결정적 SHA-256은 두 실행 모두
`ecb71ce6e9268de93c7f25a90b69a62a6b6c3182036f3b336b8cbee13ac0cb9e`다.

## 판정

- P4-폐쇄는 원시 P3를 약 26~63배 줄이지만 동치류는 여전히 수천~만 개다.
- 각본가 P2 함수류는 약 4~6배만 줄어 4,795~16,513개다.
- 따라서 “행동 동치류가 수백 개면 바로 전체 전략 탐색” 조건은 만족하지 않는다.
- 2일차 100상태 표본을 다음에 잴 때 이 두 동치류의 곱을 간선 목록으로 만들면 안
  된다. 대상별 국소 효과 관계나 목적지 CSP/DP로 전이 관계를 더 분해해야 한다.
- 이번 결과에는 2일차 전체 상태 증가율, 축 독립 상한, 잔량 근사 오차를 포함하지
  않는다. 지시한 순서대로 행동 동치류 규모만 먼저 확정했다.

후속 판정에서 `15,558 × 10,567 ≈ 1.64억`이 한 상태의 하루 전개에도 크다고
확정되어 전체 상태의 2일차 표본 계획은 종료됐다. 완전 opening book과 전체 상태 공간
사전 열거는 불가이며, 이후 계측은 한 상태의 전경 탐색으로 전환한다.
