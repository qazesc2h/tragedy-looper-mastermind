# 「못된 고양이」 A~E 지침 대조

대상은 `community:naughty-cat`, 메이드 시작 장소는 시나리오 지정값인 학교로 계산했다.
아래 핵심 결과에서 A~E 생성 예외는 없었다.

## 회수된 의도

| 원문 의도 | 생성 지침의 근거 | 판정 |
|---|---|---|
| 검은 고양이를 5일까지 생존 | A의 미래 변경 계획 경로가 최소 5일이며, 5일 나비의 날갯짓 범인 검은 고양이를 사건 단계까지 생존·등장 상태로 유지하라고 경고 | 회수 |
| 검은 고양이가 매 루프 신사에 음모 1개 | B 자동 발동 주의와 C 장소 음모 수단에 검은 고양이 특성·루프 시작·신사 음모 1개를 표시 | 회수 |
| 5일 나비의 날갯짓 범인은 검은 고양이 | A 경로 경고와 B 사건 일정에 날짜·사건·범인을 함께 표시. 효과가 없어도 발생 이력이 남음을 명시 | 회수 |
| 소녀에게 음모 2개 미끼 | C의 `나와 계약하자!` 가짜 패배 조건이 아이돌·재벌가 손녀를 소녀 후보로 계산하고, E 개시 배치가 해당 C 기여를 사용 | 회수 |
| 정보원이 룰 X를 밝힘 | B 주인공 수단에 정보원 우호 5의 룰 X 선언·다른 활성 룰 X 공개를 표시 | 회수 |
| 역할 3개로 최후의 싸움이 쉬워짐 | D가 선택 룰 공급 역할 3종(광신도·시간 여행자·선동가)과 좁은 후보 폭에 따른 역전 위험을 표시. 아웃사이더의 룰 외 역할은 별도라고 구분 | 회수 |
| 신수 우호 무시가 광신도를 단정하지 않음 | B가 기본편 우호 무시 후보 5개(살인 청부업자·흑막·광신도·마녀·변수)를 열거하고 광신도는 그중 하나라고 경고 | 회수 |

신사 음모 2개는 `미래 변경 계획`의 실제 패배 조건이 아니다. 원문 근거상 실제 조건은
나비의 날갯짓 발생이며, 생성 지침은 신사 음모를 C의 `봉인된 것` 미끼로 분리한다.
검은 고양이 특성의 자동 음모 1개와 각본가 음모 카드를 결합해 그 미끼를 만들 수 있다.

## 현재 정적 A~E가 그대로 회수하지 못한 문장

- “인과율을 먼저 공개한 다음 망상 확대 바이러스를 공개”라는 루프별 공개 순서
- “1루프에는 살인 계획, 2루프 이후에는 알아챈 역할에 따라 배제”라는 루프별 위장 전환

현재 A~E는 게임 전 단일 상태의 위험·미끼·은폐·첫날 배치를 계산하며, 여러 루프에 걸친
공개 순서를 계획하지 않는다. B는 정보원 능력과 두 룰 X의 노출 수단을, C는 현재 가능한
가짜 패배 조건을 각각 표시하지만 이 둘을 시간 순서가 있는 계획으로 합성하지 않는다.
이를 맞추려면 향후 공개 이력과 현재 가설 공간을 입력으로 하는 루프별 지침 계층이 필요하다.

## 특수 규칙 영향

각본가 우호 금지는 손패에서 삭제하거나 소진하지 않고 시나리오 특수 규칙으로 배치 금지한다.
따라서 E의 모든 추천은 공통 합법성 검사를 통과하며 우호 금지를 포함하지 않는다. B·D도
정보원에게 우호 금지를 놓아 시간 여행자를 노출시키는 불가능한 경로를 제안하지 않고,
A는 이 카드를 사용할 수 없다는 전제에서 시간 여행자 경로의 주인공 대응을 설명한다.
