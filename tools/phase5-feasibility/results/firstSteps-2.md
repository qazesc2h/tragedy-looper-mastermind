## 정정 결론

이전 결과의 초기 리더 3배와 P2 제출 순서 6배는 canonical 분기가 아니었다.
초기 리더는 주인공 번호를 현재 리더 기준 상대 좌표로 순환 치환하고, P2/P3 배치는
`(소유자, 카드, 대상)` 집합으로 정렬했다. 뒷면 배치는 각 단계마다 하나의 동시 공개
이벤트로 기록한다.

P3의 368,640개에는 별도의 제출 순서 6배가 들어 있지 않았다. 고정 리더 순서에서
소유자 0·1·2의 최종 배정 하나가 정확히 한 번 생성되기 때문이다. 따라서 총 축약은
예상한 108배가 아니라 18배다.

```text
이전 420,426,547,200 / 리더 3 / P2 순서 6
  = 23,357,030,400
```

수정 후에도 첫날 P2×P3 계층은 승인된 1억 중단선의 233.57배다. 따라서
`firstSteps:2`의 완전 canonical opening book은 승인된 프로필에서 여전히 **불가**다.
다만 이전 4,204억 판정은 폐기하며, 불가 판정의 근거는 정정된 233억이다.

P3 전체는 중단 조건 때문에 생성하지 않았다. 다음 계층 수는 다음과 같이 검증했다.

1. 초기 리더 0·1·2를 각각 만들었으며 canonical root 해시가 하나로 합쳐졌다.
2. P2는 순서 없는 완성 프로필을 실제 `legal.ts`로 검증해 63,360개를 열거했다.
3. P2 자식 하나에서 P3 generator를 끝까지 실행해 368,640개가 모두 고유함을 확인했다.
4. P3는 `8³ × P(10,3) = 512 × 720 = 368,640`이다. 첫날에는 사망자와 소진
   카드가 없어 추가 감소가 없다. 주인공끼리 대상이 겹치면 `legal.ts`가 막고,
   각본가 대상과의 겹침은 허용한다.
5. P2 부모 63,360개와 P3 소유자별 최종 프로필은 canonical 키에서 각각 구분되므로
   `63,360 × 368,640 = 23,357,030,400`이다.

P2 식은 `528 × C(10,3) = 63,360`이다. 세 카드가 모두 다른 경우와 불안+1 두 장을
쓰는 경우를 물리적 카드 수 제한대로 포함하되, 같은 완성 배치의 3! 제출 순서는
한 번만 센다.

## N / M / K

범위는 첫날 각본가의 순서 없는 P2 3장 프로필이다.

| 분류 | 수 | 전체 대비 |
|---|---:|---:|
| N — 전체 합법 프로필 | 63,360 | 100% |
| M — 어떤 합법 P3 대응에서라도 실제 해결 결과에 관여 가능한 프로필 | 62,448 | 98.56% |
| P3 카드 없이 즉시 보드 변화를 만드는 프로필 | 56,056 | 88.47% |
| K — 보수적으로 블러핑 신호까지 보존 | 63,360 | 100% |

M은 각 의미론적 각본가 카드×대상 90개에 대해 실제 `resolveActions`를 사용해
단독 결과와, 같은 대상에 놓을 수 있는 주인공 카드 8종 각각의 전후 결과를 비교했다.
그중 28개는 어떤 대응에서도 물리 결과에 관여하지 않았다. 모두 장소에 놓인
`불안+1`, `불안-1`, `불안 금지`, `우호 금지`, 이동 3종이다. 이 28개만으로 이루어진
P2 프로필은 912개다.

그러나 912개를 제거할 수 있다는 뜻은 아니다. 뒷면의 대상 선택과 P4에서 공개되는
카드 종류는 서로 다른 공개 신호이며, 어떤 신호가 블러핑 가치가 전혀 없는지는
주인공의 믿음·추론 모델 없이는 증명할 수 없다. 따라서 안전하게 제거할 수 있는
프로필은 0개이고 K=N이다. 이 때문에 무효 배치의 존재는 완전 열거 불가 판정을
뒤집지 않는다. 휴리스틱 탐색에서는 별도 우선순위로 낮출 수 있지만 opening book의
완전성 기준에서는 유지해야 한다.
